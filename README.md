# Quiz de Geografía Mundial

Juego interactivo desarrollado en Python con `tkinter` sobre capitales, ríos y montañas del mundo. Cuenta con sistema de vidas, puntaje, selección aleatoria de preguntas y límite de tiempo por respuesta.

## Instrucciones de ejecución

1. Asegúrate de tener Python 3 instalado.
2. Verifica que el archivo `preguntas.txt` esté en la misma carpeta que el código fuente.
3. Ejecuta el siguiente comando en la terminal:

```bash
python quiz_geografia.py
